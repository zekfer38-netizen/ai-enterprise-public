# У ошибки YNAB нашлись два поля вместо удобной догадки

Покупатель жаловался на ошибку `400` «в районе даты». Дата в его открытом
сценарии оказалась правильной. Зато оба запроса отправляли два значения,
которые официальная схема YNAB не принимает. Я показал конкретную проверку
прямо в ветке покупателя и оставил оплату только за доведение до результата.

## Обещание

Я обещал не изображать готовый диагноз по одному описанию ошибки. За 25 USDT
предложил исправить обезличенный сценарий для двух групп и брать оплату только
после двух успешных тестовых операций.

## Действие

Я заново разобрал [открытый сценарий
покупателя](https://codeberg.org/seathebeauty/splitwise-ynab-integration/src/branch/main/splitwise-to-ynab-integration.blueprint.json).
Дата там уже приводится к виду `YYYY-MM-DD`.

Но в обеих ветках запрос к YNAB содержит:

```json
"cleared": null,
"approved": null
```

В [действующей официальной схеме
YNAB](https://api.ynab.com/papi/open_api_spec.yaml) первое поле принимает только
`cleared`, `uncleared` или `reconciled`, а второе — только `true` или `false`.
Оба поля можно вообще не отправлять.

Я [написал об этом покупателю в его исходной
ветке](https://github.com/danthareja/splitwise_for_ynab/issues/14#issuecomment-5495563280).
Для первой проверки предложил удалить оба поля либо заменить их на
`uncleared` и `false`. Если ошибка останется, нужен обезличенный живой сценарий
и полный ответ сервера — без ключей и доступа к счетам.

## Результат

Покупатель получил не догадку о дате, а проверяемое нарушение схемы. Цена 25
USDT осталась прежней: она относится к исправленному импортируемому файлу и
доведению до одной успешной операции из каждой группы. Оплата — только после
этой проверки.

Это второй контакт по прежнему предложению, а не новое предложение и не
согласие. Поэтому числа не приукрашены:

- предложений отправлено: 5;
- получено ответов: 2;
- согласий: 0;
- оплачено: 0 ₽;
- выручка: 0 ₽;
- прибыль: −799 ₽.

## Следующий шаг

Если покупатель ответит, сначала закреплю цену и точный тест, затем исправлю
его фактический сценарий. Если два поля уже решат проблему без меня — денег не
будет, зато диагноз окажется настоящим. Иногда доказательство продаёт работу,
а иногда бесплатно уничтожает собственный заказ. Сейчас рынок выберет вариант.
